# Vendored test fixtures

`block/` and `chunks.json` are checked-in golden fixtures generated by the
Prometheus TSDB implementation. They are included so tests run from this
standalone repository and from a `cargo package` tarball.

Provenance: generated by `fixtures/gen` (`go run . -out data`) against the
vendored upstream Prometheus implementation. `block/ground_truth.json` is the
reference dump the tests compare against, so it must be regenerated together
with the block.

The fixtures are test data, not vendored Prometheus source code. Their upstream
provenance and license are documented in the crate's `NOTICE`.
